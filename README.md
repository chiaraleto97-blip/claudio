# Claudio

Lezioni brevi, come nelle app per le lingue, per imparare Claude e GitHub.
Fa parte del corso **IDEA^IA** per docenti.

Quattro percorsi: Le basi, Avanzato (connettori, ricerca, file e skill, memoria,
Claude fuori dal browser), Claude Code e GitHub.

- App: https://chiaraleto97-blip.github.io/claudio/
- Locandina con il QR da stampare: https://chiaraleto97-blip.github.io/claudio/qr.html

L'app si installa sul telefono e sul computer e funziona anche senza rete dopo la
prima apertura. I progressi restano sul dispositivo di chi la usa: l'app non
raccoglie dati.
